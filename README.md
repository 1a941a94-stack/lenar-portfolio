# CariGold Full-Stack Systems Portfolio

A responsive static portfolio focused on custom SaaS, marketplaces, AI workflows, CRM systems, API integrations and automation.

## Interactive demo concepts

The portfolio contains four intentionally different product demos:

1. **SaaS Operations** — recurring revenue, plans, billing health and account operations.
2. **Multi-Vendor Marketplace** — orders, vendor health, commissions, moderation and settlement flow.
3. **AI Document Workflow** — document ingestion, extraction, confidence thresholds, validation and human review.
4. **Custom Sales CRM** — Kanban pipeline, weighted forecast, tasks and workflow automation.

Each demo is explicitly labelled as a demo concept, not a client case study.

## Stack

- HTML
- CSS
- Vanilla JavaScript
- No build step
- No runtime dependencies

## Deploy

Deploy the repository root as a static site. Vercel, Netlify, Cloudflare Pages and GitHub Pages all work.
